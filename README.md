# LAST SIGNAL — The Final Transmission

Android-first, offline Godot 4.3 space exploration prototype. Developer: Roohu.

## Current playable prototype
- Aurora-7 spacecraft in orbit, with planets and a starfield.
- Land on Aetheria and explore with a third-person astronaut.
- Touch-drag on the left side to move.
- Scan, collect, land/orbit, and save buttons.
- Oxygen, fuel, resource counter, scripted ORION messages.
- Offline JSON save.

**This is an early prototype, not the complete game.** The Android build and actual device gameplay still need testing.

## Build on GitHub from your Android phone
Open the repository's **Actions** tab and select **Build Android APK**. Wait for a successful run, download the **LastSignal-Android-APK** artifact, extract the APK, and install it.

If the workflow fails, inspect the failed job log; the Godot Android export configuration may need adjustment.

## Future development
Improve touch controls and spaceship piloting; build distinct alien planets, creatures, base construction, quests, survival systems, audio and polished graphics. The project does not need an AI API key.
